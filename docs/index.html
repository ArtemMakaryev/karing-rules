Готовые правила маршрутизации для Karing

Российские сайты идут напрямую, заблокированные и зарубежные — через ваш сервер, реклама и вредоносные адреса блокируются. Правила обновляются сами.

Установка

Сервер уже добавлен в Karing:

  1. Нажмите кнопку ниже на устройстве, где установлен Karing, и подтвердите импорт.
  2. Выберите свой сервер заново (нижняя панель → выбор сервера): после импорта выбран «Auto Select».

Новая установка Karing:

  1. Сначала добавьте подписку на свой сервер в Karing.
  2. Затем нажмите кнопку ниже и подтвердите импорт.
  3. Выберите свой сервер (нижняя панель → выбор сервера): после импорта выбран «Auto Select».
Установить правила в Karing

Если кнопка не открывает Karing, скопируйте ссылку и откройте её в браузере на устройстве с Karing:

karing://restore-backup?url=https%3A%2F%2Fraw.githubusercontent.com%2FArtemMakaryev%2Fkaring-rules%2Fmain%2Fkaring%2Frules.zip
Что важно знать
  • Импорт заменяет ваши текущие группы маршрутизации (Diversion Rules). Подписка на сервер сохраняется.
  • После импорта Karing включает режим TUN — это обычный VPN-режим Karing.
  • Импорт сбрасывает выбор сервера на «Auto Select»: выберите сервер заново.
  • Импорт выключает Rule Set Direct Download (Настройки → Diversion → Rule Set): если вы пользуетесь ею, включите снова.
  • Если у вас есть аккаунт у владельца, он пришлёт личную ссылку в одно касание: она ставит сразу ваш сервер и эти правила.
  • Новая группа или смена действия у группы подтягиваются только повторной установкой по этой ссылке; после неё снова выберите сервер.
  • Ожидается, что наборы правил Karing перекачивает сам примерно раз в сутки; сразу — через Настройки → Очистить кэш.
